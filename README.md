# Josiah Ferrer Personal Website

This folder is prepared for a GitHub Pages user site.

## Expected GitHub Pages setup

Create a public repository named `drauthorcat.github.io`, then place the contents of this folder at the repository root. The entry file is `index.html`, which is the format GitHub Pages expects for a static user site.

## Before publishing

The final site URL is `https://drauthorcat.github.io/`. Keep it in sync in:

- `index.html`
- `mobile.html`
- `robots.txt`
- `sitemap.xml`

Update the placeholder contact email and biography text before making the site public.

Confirm that all fonts in `assets/fonts/` are licensed for web use and redistribution in a public repository.

For future content changes, see `CONTENT_MAINTENANCE.md`.

After the site is live, submit `https://drauthorcat.github.io/sitemap.xml` in Google Search Console. Search engines can crawl the site without this step, but submitting the sitemap helps discovery and gives you error reporting.
